# 🤖 Autonomous Vehicle Control System | Robotic Science Coursework

โปรเจกต์พัฒนาระบบควบคุมยานพาหนะอัตโนมัติ (Autonomous Vehicle) ซึ่งเป็นส่วนหนึ่งของรายวิชาวิทยาการหุ่นยนต์ (Robotic Science) ระดับชั้นปริญญาตรีปีที่ 3 ภาคเรียนที่ 1 

---

## ✨ ฟีเจอร์เด่นของระบบ (Features)
* **Self-Navigation:** ระบบควบคุมการเคลื่อนที่และนำทางยานพาหนะให้สามารถขับเคลื่อนและตัดสินใจเส้นทางได้ด้วยตัวเองโดยอัตโนมัติอย่างแม่นยำ 
* **Sensor-Driven Obstacle Avoidance:** ลอจิกการหลบหลีกสิ่งกีดขวางอัจฉริยะที่ทำงานบนฮาร์ดแวร์เซ็นเซอร์ตรวจจับวัตถุ พร้อมคำนวณระยะทางและตอบสนองต่อเหตุการณ์ตรงหน้าแบบเรียลไทม์ 
* **Calibrated Control Algorithms:** ออกแบบและปรับแต่งอัลกอริทึมการคำนวณทิศทางรอบหมุนและการจ่ายไฟ เพื่อความเสถียรและความเที่ยงตรงสูงสุดในการเคลื่อนที่ของตัวรถ 

---

## 🛠️ เครื่องมือและฮาร์ดแวร์ที่ใช้ (Hardware & Tech Stack)
* **Microcontroller Board:** Arduino UNO R4
* **Programming Language:** C / C++ 
* **Core Components:** อุปกรณ์ควบคุมลอจิก (Control Logic), เซ็นเซอร์ตรวจจับวัตถุ/สิ่งกีดขวาง (Sensors) และชุดมอเตอร์ขับเคลื่อน 
* **Development Environment:** Arduino IDE
